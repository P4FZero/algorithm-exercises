# Exercises

This directory contains fundamental C# exercises focused on logic building and language fundamentals.

The exercises are organized progressively, starting from basic sequences and moving towards more structured programming concepts such as functions and procedures.

## Organization

Exercises are grouped by topic:

- **BasicSequences**
  Sequential execution, variables, input/output, and basic arithmetic operations.

- **BasicConditions**
  Simple conditional logic using `if` and `else`.

- **CompoundConditions**
  More complex conditional logic using combined expressions (`&&`, `||`, etc.).

- **WhileLoop**
  Repetition using `while` loops for condition-controlled iteration.

- **WhileLoopWithFlag**
  `while` loops using a flag (boolean control) for more flexible loop termination.

- **DoWhileLoop**
  Repetition using `do-while` loops, where the loop body executes at least once.

- **ForLoop**
  Iteration using `for` loops, usually with a known number of repetitions.

- **Arrays**
  Arrays, indexing, traversal, and basic data manipulation.

- **Procedures**
  Exercises focused on methods that perform actions (void methods) and improve code modularity.

- **Functions**
  Exercises focused on methods that return values, reinforcing reusable logic and problem decomposition.

## Study Approach

- Start from the top and progress gradually.
- Focus on clarity and correctness rather than complexity.
- Revisit exercises to improve or refactor solutions over time.

## Notes

- Exercises are intended for practice and learning.
- There is no single correct solution.
