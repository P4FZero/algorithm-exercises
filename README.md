# Programming Exercises Repository

This repository contains a collection of programming exercises organized by programming language and learning area.
It is intended for continuous practice, skill improvement, and future expansion to other programming languages.

Currently, the exercises are implemented in **C#**.

## Project Structure

The repository is organized by programming language.
Each language has its own directory, and inside each one the content is divided into learning areas.

### Common learning areas include:

- Fundamentals – programming fundamentals and basic logic
- OOP – object-oriented programming concepts
- API – API development and integration

### Example Directory Structure

```
CSharp/
├── Fundamentals/
│   ├── BasicSequences/
│   ├── BasicConditions/
│   ├── ForLoops/
│   ├── Arrays/
│   └── ...
├── OOP/
└── API/
```

Other learning areas (such as OOP and API) will contain more advanced topics and practical applications and may follow a similar category-based organization.

## Purpose

- Practice programming fundamentals
- Improve problem-solving and logical thinking
- Compare implementations across different languages
- Build a personal reference of common programming patterns

## How to Use

1. Choose a programming language folder (e.g., CSharp).
2. Navigate to a topic directory (e.g., Fundamentals/BasicSequences).
3. Read the exercise description (usually provided as comments).

## Notes
